**No phase is complete merely because its code is committed.** Evidence must correspond to the actual source revision, environment and live user journeys.

## 90-day checkpoints

- Days 1-14: engineering standards, repository ownership, customer discovery.
- Days 15-30: protected Gratog checkout, inventory, recovery and fulfillment certification.
- Days 31-45: cloud pilot with budget and deletion evidence.
- Days 46-60: reusable paid business automation.
- Days 61-90: paid customer tests, measurable recurring value, iterate on product.

## A16 notifications

Only announce scoped build milestones by accurate wording such as "engineering foundation preflight built and tested; production certification pending." Never use the separate protected OPEE full-completion signal unless the independent completion authority issues the necessary signed receipt.
